# CodeGuessr

A lightweight programming-language guessing quiz. Players inspect a short code snippet and guess the language from syntax, idioms, standard library calls, module systems, operators, and other language-specific fingerprints.

## Stack

- SvelteKit
- TypeScript
- Vite
- Prism syntax highlighting
- Static TypeScript dataset
- `localStorage` for best score and selected mode

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run check
npm run build
```
